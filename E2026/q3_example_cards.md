# 问题三典型解释卡与反例卡

依据：冻结问题二模型的附件4预测、全模态及十位置局部遮蔽、ASR时间映射，以及用户提交的20条人工回看。所有概率变化均是输入归零后的**敏感性**，不是因果贡献；附件4无情感真值。

## 案例A：09号，人工回看基本相符

| 项 | 结果 |
|---|---|
| 原文本 | “(uhh) I did not like this movie at all, I would not recommend it” |
| 极性/强度 | 负向；-1.894；负向概率0.956 |
| 三模态正向支持占比 | 文本0.993、语音0、视觉0.007；按“遮蔽后原类别概率下降的正值”归一化 |
| 主参考模态 | 文本，仅在当前遮蔽定义下成立 |
| 文本整模态遮蔽 | 原负向概率由0.956降至0.376，下降0.580 |
| 语音整模态遮蔽 | 原负向概率反而升至0.963，差值-0.0069；不应解释为“语音支持负向” |
| 视觉整模态遮蔽 | 原负向概率降至0.952，下降0.0043 |
| 最大局部文本段 | 位置10–19，原话片段“movie at all, I would not recommend it”；遮蔽后原负向概率下降0.0643，预测强度变化-0.638 |
| 原视频回看起点 | ASR估计约1.75–5.04秒；题给词与ASR精确匹配13/14，仍非人工逐词真值 |
| 人工记录 | 用户在审查页选“证据与预测基本相符”，并确认核查了整体与局部位置；无文字备注 |

这张卡展示强文本证据与模型负向输出一致，同时暴露语音支路不提供正向支持。视觉差值很小，不应从画面臆造表情解释。

## 案例B：15号，人工回看矛盾

| 项 | 结果 |
|---|---|
| 题给文本 | “However, despite their poverty, the family prioritize education because they believed in its power to transform lives” |
| 极性/强度 | 正向；+1.437；正向概率0.918 |
| 三模态正向支持占比 | 文本约0.992、语音0、视觉约0.008 |
| 自动局部文本片段 | “transform lives”在遮蔽下原类别概率下降0.0414；该位置不提供可信视频秒数 |
| 人工记录 | 用户选“矛盾”，补充矛盾依据是原话，但不能复述具体字句与时间 |
| 自动语音诊断 | faster-whisper base.en提示前约5.44秒在讲父亲去世与家庭经济困难，题给句子仅在尾段出现开头；这是机器转写候选，需人工复核 |
| 时间证据 | 题给文本与ASR仅4/17词精确匹配；锚点拒绝，全部局部位置的秒数未验证 |

15号是高置信预测与人工判断冲突的反例。原音轨与题给整句疑似错配，模型偏向积极措辞；不能由此唯一认定错误原因，也不能修改题给转写或用附件4再训练。论文应以“人工反例及可能机制”呈现。
