# 2026 E 题：截图思路复核与数据处理重排

依据：用户提供的三张思路截图、E 题题面、附件1至4、已运行的 verify_pitfalls.py / pitfall_checks.json 和基线结果。本文件把截图中的观点视为待核假设，以下数字均来自本地数据检查。

## 1 截图中可保留的主线

1. 三问共用“有时间定位的三模态表示 → 局部缺失鲁棒预测 → 可回看证据的解释”主线。
2. 训练、验证和专项推理必须选同一 aligned 或 unaligned 版本；附件3、4没有标签，不能拿来调参或报准确率。
3. 问2输出极性和连续强度，验证集至少给 Accuracy、F1、MAE、Pearson，并按缺失模态、位置、时长分层。
4. 问3需要模态作用程度和原始文本／语音／画面证据。注意力可作可视化，但应辅以遮挡或删除试验与回看核对。

## 2 必须修正的数据理解

## 3 字段与标签的冻结口径

- aligned_50.pkl：train 3395、valid 728、test 727；三组片段 ID 和视频 ID 均无交叉。
- 分类标签 0=负向、1=中性且强度恰为0、2=正向。不可用“强度大于等于0即正向”。
- 附件3：对齐版30个文件，每个顶层是 test 字典，字段为 text_bert / audio / vision，未带 id；输出行用文件名编号建索引并保持文件名映射。
- 附件4：对齐版20个文件是直接样本字典，含 id / raw_text / text / text_bert / audio / vision；id 与文件编号应逐一核对。附件3、4的包裹层不同，读取器需分别适配。
- 本地核验：附件3对齐版30个样本中29个的音频、视觉零位掩码完全相同；附件4对齐版20个样本中19个也相同。这种共同零位既可能来自对齐处理，也可能包含专项扰动，单靠零值无法分离。

## 4 重排后的执行顺序

### 第一步：冻结样本清单与接口

将附件1至4记录为四类数据源，统一输出 sample_id、source、version、text_bert、audio、vision、各自长度／有效位、观测零位、原始文件路径。附件3从文件名生成 sample_id，附件4读取 id。检查标签映射、跨划分与附件1重叠，并保存审计 JSON。对于附件3，自身没有缺失真值字段，接口不要伪造。

### 第二步：完成问1的100条原视频处理

保留原样本与原标签。先核对音画和转写，再给词语或所选时间窗建立起止秒数；抽取文本、音频、视觉特征，明确聚合、截断、填充和失败标记。产出100条总表、特征文件、逐位置到原视频的映射与至少一个典型样本可视化。若采用等时间网格，明确其与附件2 aligned_50 并非同一种对齐口径。

### 第三步：构建可部署基线，再设计缺失模型

先用 text_bert 的同一编码器处理附件2训练/验证与附件3，建立文本单模态、音视频单模态和简单融合对照。当前哈希词元＋均值汇聚诊断基线 Accuracy 0.455、MAE 0.801，低于多数类0.464与训练均值0.781，不能作最终模型。新模型须保留时间位置与模态观测状态；在训练数据上自行注入连续缺失并保存注入掩码，按模态、位置、时长做固定种子验证。原始零位保持原样，不能当作合成缺失标签。

### 第四步：验证、冻结与专项推理

只在 train 学参数、valid 选结构／超参／阈值。使用独立的缺失模拟方案评估鲁棒性；冻结后可在附件2 test 做一次最终有标签检验，不能回头据此调参。之后对附件3、4全量推理，输出预测 CSV；附件3/4无标签，不计算其四项性能指标。

### 第五步：解释与论文证据

对每个附件4样本做跨模态移除和局部窗口遮挡，给出预测变化、主要参考模态、局部证据位置，并核对关键证据在原视频／语音／文本的真实时间。位置到秒数的映射需从视频和转写建立，不能把50个位置线性映射成50个等长时段。13号视觉全零应标记为不可提供视觉局部证据。解释结果是模型敏感性证据，不宣称严格因果。
