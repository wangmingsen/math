# 2026 E 题问1：100条原视频初版特征

本阶段已对附件1全部100条原视频执行真实音画解码和特征提取，成果保存在项目本地 outputs/q1_features。这里是可复现基线，不是最终高精度逐词对齐或情感模型。

## 运行与结果

命令：python E2026/q1_extract.py --data-root ../E题数据/E题数据 --out ../outputs/q1_features
验证：python E2026/q1_validate.py --data-root ../E题数据/E题数据 --features ../outputs/q1_features --out E2026/q1_validation_summary.json

验证结果：100条全部成功、0失败；100个主键与原标签表双向全匹配；生成100个 NPZ 特征文件和100个 JSON 时间映射文件。文本、音频、视觉特征形状分别为 (50,259)、(50,21)、(50,21)，全部为有限数值。50个时间窗均有实际画面帧记录。特征文件合计824239字节，映射文件合计1265728字节；不含模型参数。

## 方法定义

| 模态 | 初版特征 | 时间来源 |
|---|---|---|
| 文本 | 给定英文转写分词，256维确定性词元哈希频率 + 词数、平均词长、标点比例 | 用20毫秒音频能量计算累计语音权重，按权重分位点为词元分配估计起止秒数；再落入50个等时长视频窗 |
| 音频 | 16个对数频带能量、RMS、过零率、频谱质心、带宽、平坦度，共21维 | FFmpeg解码为16kHz单声道，逐时间窗计算 |
| 视觉 | HSV直方图16维、亮度、对比度、人脸检测标记、人脸面积比例、相邻采样帧运动量，共21维 | OpenCV顺序解码，从每窗中心附近抽取实际帧并记录帧时间 |

每个样本 JSON 记录原视频相对路径、50窗起止秒数、画面帧时间、估计词元时间、词元到窗的映射和特征维度。原始视频与标签未被修改；标签不参与特征计算。

## 重要边界

1. 文本起止秒数是基于语音能量的单调估计，不是人工标注或声学强制对齐。不能以当前时间戳宣称精确定位到原视频中的每一个词；在论文中须标记估计方法并做人工核查，最好升级为可复核的强制对齐。
2. 问1的50窗是等时长时间网格，附件2 aligned_50 是另一套题给序列位置。两者不能按相同索引直接拼接。问2/3继续使用附件2训练/验证，问1这100条特征不进入训练。
3. 词元哈希和颜色／人脸特征是低成本可复现基线，对情感语义和面部动作的表征能力有限。若用于正式论文，需要与更有情感辨识力的预训练文本、声学和面部特征做对比，并验证典型样本。
4. 由于附件1有7条与附件2测试集重叠，100条样本的原标签不得用于问2/3模型训练或调参。
