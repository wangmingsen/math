# 问题三：附件4候选预测、局部解释与原视频回映

日期：2026-09-23。本阶段冻结问题二已选定的模型和 BERT 编码器，对附件4对齐版本的 20 条样本作无标签预测与遮蔽敏感性分析。附件4没有题给情感标签，因此以下结果**不是准确率或解释正确率**。

## 输入核查与方法

1. 附件4的 20 个对齐 PKL 均含 `raw_text`、`text_bert`、`audio`、`vision`，各有对应原视频。复用问题二的 BERT ONNX、分段池化、PCA 和晚期融合训练头；未在附件4上重训或调整权重。
2. 原文本经同一 tokenizer 还原到 `text_bert` 的词元位置。20/20 与已保存词元前缀一致。07、18 两条超出 50 位，模型只看到了前半段；这些片段以截断标记呈现，不把完整原文冒充模型输入。
3. 对每条样本分别遮蔽完整文本、音频、视觉，记录原预测类别概率的下降和连续强度的有符号变化。再将 50 位分为 5 个十位置区间，逐段遮蔽并记录局部变化。正向概率下降的份额仅作本模型的支持分解；负值意味着遮蔽后原类别概率反而上升。整模态置零可能超出训练分布，因此这些量是**输入遮蔽敏感性**，不是因果重要性、可信度校准或人的情感依据。
4. 对齐 PKL **没有原视频的秒级时间戳**。用 `faster-whisper base.en` 对原视频音轨转写，以精确匹配词作锚点，再按词中心中点估计词界，将 BERT 词元对应到大致秒数。19 条有可接受的 ASR 锚点，15 号匹配不足，所有秒数留空。ASR 估计时间必须由人工回看确认，不等同于题给对齐真值。音频/视觉的十位置区间沿用词元位置到估计时间的映射，并非逐帧特征的原始时间戳。

## 核查结果

| 检查项 | 结果 |
|---|---:|
| 唯一样本和原视频 | 20/20 |
| 预测类别：负/中性/正 | 8/4/8 |
| 主要正向支持模态：文本/音频/视觉 | 20/0/0 |
| 文本正向支持份额中位数 | 约 0.970 |
| 有 ASR 估计时间/不提供秒数 | 19/1（15号） |
| 文本超过 50 位 | 2（07、18号） |
| 视觉全零 | 1（13号） |
| 分类与强度需人工复核 | 2（07、14号） |

文本占主导与问题二预设的分类 90% 文本融合权重及音视频支路较弱一致，**不能据此证明视觉和语音无用**。13 号视觉全零，不展示视觉局部依据。07、14 号被分到中性，但连续强度分别约 +0.872、+0.823；保留这两个冲突供论文分析，不在看过附件4后悄悄改模型。15 号只给词元位置，不给假精确秒数。

以 09 号为可复核样例：模型预测负向；文本位置 10–19 的片段为 “movie at all, I would not recommend it”，遮蔽后原预测类别概率下降约 0.281，强度变化约 -0.556；其视频时间约 1.75–5.04 秒，**仅为 ASR 估计**。页面可从该位置跳转原视频，人工需要确认听到的内容、画面及时间偏差。

## 交付与复现

本地 `outputs/q3_A4/explanation_review.html` 可逐条播放 20 个原视频，查看预测、逐模态和局部遮蔽结果，记录人工判断并导出 CSV。审查记录默认保存在浏览器本地，导出前不要清除站点存储。页面引用本地原视频，所以需要在保有同一数据目录的电脑上打开；它和逐条转写、原视频、模型权重均不上传公共仓库。公开仓库只同步脚本和聚合 JSON。

```powershell
.\.venv-q1\Scripts\python.exe team-sync/E2026/q3_prepare_a4.py --data-root E题数据/E题数据 --model model_cache/bert/bert-base-uncased-int8.onnx --tokenizer model_cache/bert/tokenizer.json --out outputs/q3_A4
.\.venv-q1\Scripts\python.exe team-sync/E2026/q3_time_map.py --manifest outputs/q3_A4/manifest.csv --tokenizer model_cache/bert/tokenizer.json --model-cache model_cache --model base.en --out outputs/q3_A4/time_maps
.\.venv-q1\Scripts\python.exe team-sync/E2026/q3_explain.py --data-root E题数据/E题数据 --text outputs/q3_A4/A4_text.npz --time-maps outputs/q3_A4/time_maps --model outputs/q2_late_fusion/model_candidate.joblib --out outputs/q3_A4/explanations
.\.venv-q1\Scripts\python.exe team-sync/E2026/q3_validate_outputs.py --out outputs/q3_A4/explanations
.\.venv-q1\Scripts\python.exe team-sync/E2026/q3_build_review_cards.py --manifest outputs/q3_A4/manifest.csv --explanations outputs/q3_A4/explanations --out outputs/q3_A4/explanation_review.html
```

本地机器检查通过：20 条预测、60 行整模态遮蔽、300 行局部遮蔽；概率和为 1；13 号视觉遮蔽变化为零；15 号无秒数；07、18 号截断标记正确。下一步是人工回看疑点样本，再把“模型输出—关键证据—不确定性/失败案例”组织成论文第三问的结果。未经人工确认，不声称证据定位已经准确。
