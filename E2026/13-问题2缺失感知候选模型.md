# 问题二：共享BERT编码与局部缺失候选模型

日期：2026-09-23。本阶段使用附件2 `aligned_50.pkl` 的 train 3395 条拟合、valid 728 条选定候选结构；参数固定后在 test 727 条做一次有标签检验。附件3的30条仅作无标签预测，未参与训练、选参或计算性能。

## 处理流程

1. 文本不使用附件2独有的预计算 `text` 向量，而从附件2和附件3共有的 `text_bert`（3×50词元、注意力与句段类型）输入同一冻结 BERT base uncased ONNX 编码器，得到5个十位置片段的768维均值。PCA仅在附件2 train 拟合，片段压到48维。A2 train、valid、test 和附件3都经过完全同一路径；所有ID及顺序逐项核对。
2. 音频74维与视觉35维按原 `aligned_50` 的5个片段计算非零观测均值、观测比例和片段内部零位比例。零位只是观测模式；**不把附件3原始零位直接称为已知缺失真值**。
3. 训练集上的文本支路加入一份随机遮掉一个可见文本片段的副本。音视频支路保留完整副本，并分别加入随机连续遮蔽音频、视觉的副本（种子2026；区间约占首末非零位置跨度的15%～45%）。模型使用标准化线性分类器和Ridge回归器。
4. 晚期融合限制音视频贡献：分类概率为90%文本＋10%音视频，连续强度为80%文本＋20%音视频。权重是在开发阶段查看 valid 后选定，因此下表 valid 指标是模型选择用指标；另报一次性 test 结果作独立检验。所有类别由题给标签编码0负、1中性、2正。
5. 在 valid 固定遮蔽音频或视觉有效跨度的10%、25%、50%，位置分别为开头、中间、末尾；文本另遮蔽一个片段。指标均在原 valid 标签上计算，不在附件3上估计 Accuracy、F1、AUC、MAE 或 Pearson。

## 冻结后一次性检验与附件3

附件2 test（727条）一次性指标：Accuracy **0.609**、Macro-F1 **0.585**、Macro-AUC OvR **0.764**、MAE **0.707**、Pearson **0.599**。同一test集的训练多数类Accuracy为0.498，训练均值MAE为0.886。中性类F1仅0.398，是明确的剩余弱点。看过test后不再修改候选结构或权重。

本地 `outputs/q2_late_fusion/A3_predictions_candidate.csv` 覆盖附件3的30/30个唯一主键，类别数为负6、中性12、正12，概率和为1，强度范围约[-1.001, 0.973]，均为有限值且没有极性与强度符号冲突。附件3没有标签，这些是**候选预测，不是附件3准确率**。对应轻量训练头为 `outputs/q2_late_fusion/model_candidate.joblib`；外部冻结BERT权重不包含在该文件中。
