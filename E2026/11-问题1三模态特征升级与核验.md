# 问题一：三模态特征升级与核验

日期：2026-09-23。本阶段只处理附件1的100条视频及其题给转写；不把附件2的特征、标签或时间位置混入本产物。

## 本轮可复核结果

- 100/100条视频完成 BERT、OpenSMILE、OpenFace 提取，三支均无程序失败。按样本主键合并后，每条视频共用原视频时长内的50个等时窗口；每条均保存窗口起止秒数和源视频映射。
- 文本 `text_bert` 为 `50×768`。使用题给转写、BERT base uncased 最后一层编码器输出；WordPiece 在词内取均值，再将词中心落入对应窗口并求均值。没有词的窗口填0，`text_present` 明确标记。5000个窗口中2057个含题给文本词。
- 语音 `audio_opensmile` 为 `50×50`。OpenSMILE 2.6.0 的 eGeMAPSv02、25维逐帧低层描述符按窗口取均值和标准差。音频以 FFmpeg 解码为16 kHz单声道；完全静音的2条视频保持零向量，`audio_signal_present` 标记了4900个有信号窗口。原始OpenSMILE非有限单元数为0。
- 视觉 `vision_openface` 为 `50×35`。OpenFace 2.2.0 `FeatureExtraction` 使用随发行包提供的 `main_clnf_general` 模型，提取17个AU强度和18个AU出现值；仅对人脸跟踪成功的帧聚合。共23241视频帧，其中21967帧成功；`face_valid` 标记4612个有效窗口，4条视频无成功人脸帧。无人脸窗口的零值仅作占位，不能解释为中性表情。
- 合并脚本逐样本验证三支时间边界一致、维度固定、数值有限、无人脸窗口不含AU数值。独立验证脚本又与题给 `label-100.xlsx` 核对：100/100个主键、2166个原文词、100份映射和全部掩码均一致，问题数为0；汇总见 `q1_validation_v3_summary.json`。
- 本地交付文件为 `outputs/q1_features_v3.zip`，包含100组压缩特征、100份时间映射、总表与汇总。原视频、题给逐条转写、特征文件和模型权重仅保存在本地，不推送到公开协作仓库。


## 时间和证据链

每条记录以 `(video_id, clip_id)` 组成的样本ID连接题给转写与原视频。`mapping.json` 保留每个词的文本、估计起止时间、每个窗口的起止秒数与来源视频路径。v3将先前容易误解的 `asr_exact_word_anchor` 改为 `asr_midpoint_derived_estimate`，数值不变；这些词区间由ASR词中心和相邻中心推算，**不是人工验证的真实词边界**。100条中79条采用ASR锚点规则，21条仍使用能量加权回退。此前低匹配核查和全静音核查结果见《10-问题1低匹配与静音复核.md》；人工逐条听辨记录仍需补齐。

50个窗口对应附件1原视频的真实秒数，不等同于附件2的50个已对齐位置。三路提取方法是本项目新生成的特征，不能据此声称附件2所给74维音频或35维视觉特征也由这些工具产生。视觉仅跟踪单一人脸，在多人同屏或主体切换时需人工检查主体身份。

## 本地复现

前提：已按《08-问题1对齐改进与验证.md》生成 `outputs/q1_features_v2`，并取得题给原视频。Python环境包含 `numpy<2`、`opensmile==2.6.0`、`onnx==1.19.1`、`onnxruntime==1.30.0`、`tokenizers==0.23.2`；系统提供 FFmpeg。BERT模型为 [onnx-community 的量化 ONNX BERT](https://huggingface.co/onnx-community/bert-base-uncased-ONNX/tree/435f992954e6b5f8702ac6e954cf892aef89363b/onnx)，文件 `onnx/model_int8.onnx`，本地SHA256为 `6253F42DB3ED22F619134F0B0858862F44203FB687943A20E9202042B73C5E01`；分词器取 [google-bert/bert-base-uncased](https://huggingface.co/google-bert/bert-base-uncased/blob/main/tokenizer.json) 的 `tokenizer.json`。OpenFace取 [2.2.0 Windows发行包](https://github.com/TadasBaltrusaitis/OpenFace/releases/tag/OpenFace_2.2.0)；本项目指定发行包自带的 `model/main_clnf_general.txt`。

```powershell
.\.venv-q1\Scripts\python.exe team-sync/E2026/q1_bert_extract.py --q1-features outputs/q1_features_v2 --model model_cache/bert/bert-base-uncased-int8.onnx --tokenizer model_cache/bert/tokenizer.json --out outputs/q1_bert
.\.venv-q1\Scripts\python.exe team-sync/E2026/q1_opensmile_extract.py --data-root E题数据/E题数据 --q1-features outputs/q1_features_v2 --out outputs/q1_opensmile
.\.venv-q1\Scripts\python.exe team-sync/E2026/q1_openface_extract.py --data-root E题数据/E题数据 --q1-features outputs/q1_features_v2 --openface model_cache/openface/release/OpenFace_2.2.0_win_x64/FeatureExtraction.exe --out outputs/q1_openface
.\.venv-q1\Scripts\python.exe team-sync/E2026/q1_build_v3.py --source outputs/q1_features_v2 --bert outputs/q1_bert --smile outputs/q1_opensmile --openface outputs/q1_openface --out outputs/q1_features_v3
.\.venv-q1\Scripts\python.exe team-sync/E2026/q1_validate_v3.py --data-root E题数据/E题数据 --features outputs/q1_features_v3 --out team-sync/E2026/q1_validation_v3_summary.json
```

OpenSMILE脚本将其随包配置临时复制到ASCII路径，以适配本项目的中文路径。各脚本输出汇总JSON与100行清单。OpenFace逐帧CSV只用于本地调试，不纳入v3交付包。
