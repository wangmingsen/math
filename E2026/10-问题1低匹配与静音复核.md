# 问题1：低匹配与静音样本复核

## 范围与方法

针对问题1第二版中 21 条 ASR/给定文本逐词精确匹配率不足0.60的片段，读取原始 MP4，使用 FFmpeg 解码16 kHz音频；对单声道完全为零的样本再解码双声道确认。对非静音样本使用较强的 `faster-whisper base.en`（CPU INT8）重新识别，仍以题给文本为唯一原文，按原有逐词规则复算匹配率。再与同一原视频 ID 下的给定文本比较，排查明显错用其他已给片段的可能。

本次是自动复核，**没有人工听辨，也没有把识别文本当作真值**。详细逐条结果和原文内容在项目本地 `outputs/q1_low_match_base_detailed.json`；可供组员逐条核听的表在 `outputs/q1_low_match_manual_review.csv`。这两份文件不上传公开 GitHub。

## 结果

| 类别 | 数量 | 判读 |
|---|---:|---|
| 原 MP4 带 AAC 音轨，但双声道解码 PCM 均为零 | 2 | 真正的音频内容全静音；无法做声学逐词对齐。涉及同一原视频的两个片段；原视频画面和题给标签仍保留。 |
| 音频非零，较强模型识别少于3词 | 3 | 音频可解码，但当前自动识别不足以验证转写。可能是噪声、非英语/低清晰度语音或识别失败，不能自动归因。 |
| 音频非零，识别出词但与题给文本仍低匹配 | 16 | 较强模型没有恢复可自动接受的对齐；需核听原视频与给定文本。部分识别内容连贯但与给定句子不同，属于**疑似**片段/转写不对应，尚非定论。 |
| 较强模型达到自动对齐门槛 | 0 | 21 条仍不能自动替换当前回退时间戳。 |

21 条分布于7个原视频 ID；其中6个 ID 的全部入选片段低匹配。对同源其他已给文本的自动相似度检索没有发现≥0.80的明确对应关系，因而**不能简单把这些片段改映射到另一条已给标签**。

两个全静音样本的 AAC 音轨在原文件中存在，FFmpeg 分别解码左、右声道后峰值均为0；不是单声道混音相位抵消。当前特征文件里的 `audio_signal_present` 对其50个位置均为假。其文本词时间由初版兜底算法分配，不能被表述为“语音确认的对齐位置”。

## 对当前产物的影响和下一步

1. 保留全部100条原样本、给定文本与标签，不删改原文件。问题1第二版特征不因自动识别失败而偷偷改写。
2. 两条全静音样本禁用音频证据与音频驱动的词时间解释；模型中要保留低可信度/无信号标记。其文本可用于句级特征，但词级音频时间不可用。
3. 另外19条进入人工核听清单；优先核查6个“整组低匹配”的原视频来源，再核查3条“有音频但几乎识别不到词”的片段。人工记录“转写一致/偏移/错片段/无法判定”及听到的起止时间。
4. 人工确认之前，不把这些样本当作对齐成功的例证，不据此修复 clip ID 或转写，不将推测写入论文事实。若需要变更输出，应另建 v3 并保存原版及变更日志。
