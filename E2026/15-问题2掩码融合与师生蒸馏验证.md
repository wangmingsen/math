# 问题二：掩码融合与师生蒸馏的验证集实验

日期：2026-09-24。承接《13-问题2缺失感知候选模型.md》。本轮按“先核对数据协议，再训练，再做缺失压力测试”的顺序，比较原线性晚期融合与轻量 Transformer 教师—学生方案。**新方案只用附件2 train/valid 开发，没有再次查看附件2 test 标签。**此前线性候选已经对同一 test 做过一次检验，所以不能把未来对新方案的 test 结果称作完全未触碰的独立检验。

## 1. 输入合同与掩码语义

- 全流程只使用附件2/3的 `aligned_50`，同一个冻结 BERT ONNX、词表和训练集拟合的48维 PCA。未把未对齐版临时换进专项推理。附件2 train/valid/test 共4,850条原文本与存储 token ID 完整一致或满足50位截断前缀一致；词表30,522项，`[PAD]/[UNK]/[CLS]/[SEP]/[MASK]` 分别为 0/100/101/102/103。三个划分及附件3的注意力掩码、特殊 ID 和整数 ID 域检查均通过。附件3没有原始文本，不能逐条反向验证原句与词元完全一致。
- 附件2原文超过50词元：train 234、valid 44、test 49，共327条。**这是数据表示截断，不是显卡限制。**本轮沿用题给输入，未声称解决被截断内容。
- 文本填充由题给 attention mask 定义；音视频没有显式的真实填充/观测/缺失真值。原始零行只记录为数值零，可能来自填充、抽取失败或低活动信号。训练模拟的**计划遮蔽掩码**与原本非零且确实被改变的掩码分别保存。模型把原始非零行作为弱可用性代理，不将附件3的内部零段称作已知缺失真值。
- 附件3对齐版30条中，音频与视觉各有27条包含内部零段，均无整模态全零；这只是零值分布描述，不能由此推断注入机制。

## 2. 候选模型与训练

文本以5个十位置 BERT 片段投影为48维；音频与视觉各按5个片段计算观测位置均值、非零比例和片段内部零比例。每模态5个 token，共15个 token 输入宽度64、4头、2层的 Transformer；模型使用模态、位置嵌入以及有效位置屏蔽，联合输出三分类和连续强度。这里**没有单独校准的显式可靠性门控**；注意力、非零比例和掩码只能表示可用性代理。真实零值成因不明，不能把代理解释为真实传感器可靠度。

教师用完整 train 样本训练。学生每轮随机见到完整、音频、视觉、音视双缺、文本一段缺、文本加音视缺等情形；损失包括题给分类/回归标签以及教师完整输入输出的软分类与强度目标。注入区间位于首末非零位置之间，长度随机取该跨度约10%–50%；文本训练以一整个已观测片段为单位。每轮的文本、音频、视觉计划掩码及音视频实际改变的非零行保存在本地 `injection_masks.npz`。

训练随机种子2026/2027/2028与独立的掩码种子42026/42027/42028分别固定。模型在 valid 的完整输入与音视中段双缺约25%上按预设组合分数选检查点。选择阶段没有用附件3标签，也没有再用附件2 test。三组教师在完整验证集的 Macro-F1 均值±样本标准差为 **0.590±0.007**，MAE **0.620±0.008**；三组学生分别为 **0.592±0.005**、**0.623±0.010**。蒸馏学生没有稳定压过教师，不能写成“蒸馏使分类必然提升”。

仅凭 valid 选择：三位教师概率取均值用于分类；三位教师加三位学生的强度取均值用于回归。这是新候选，不替换《13》里已有的一次性 test 结果。

| 附件2 valid，728条 | Accuracy | Macro-F1 | Macro-AUC OvR | MAE | Pearson |
|---|---:|---:|---:|---:|---:|
| 原线性晚期融合，完整 | 0.582 | 0.577 | 0.764 | 0.644 | 0.579 |
| 新教师/学生集成，完整 | **0.626** | **0.599** | **0.789** | **0.599** | **0.636** |
| 新集成，音视中段双缺约25% | 0.621 | 0.592 | 0.788 | 0.599 | 0.638 |

完整验证集中性类 F1 仍仅约0.440，不能称三类都已良好识别。以上提升是同一验证集上的候选比较，存在选择偏差；不能写成新的独立 test 提升。

## 3. 缺失压力测试与失败边界

冻结集成后，在附件2 valid 上运行169个情形：完整1个，加 T/A/V/TA/TV/AV/TAV 七类组合 × 请求比例10%/20%/40%/60% × 前/中/后 × 单块/双块。每个情形记录请求比例、计划位置数、实际改变的原非零位置数、Macro-F1、MAE及三模态全不可用数。训练先验为负/中/正约0.285/0.223/0.492；全不可用时显式返回该先验与训练强度均值，并标记低可信，避免除零或 NaN。此回退已用全零输入单独核查。

| 场景示例 | Macro-F1 | MAE | 解释 |
|---|---:|---:|---|
| 完整 | 0.599 | 0.599 | 验证基准 |
| 音视双缺40%，中段单块 | 0.594 | 0.602 | 变化较小，仍可能因为文本占主导 |
| 文本请求缺10%，中段单块 | 约0.546 | 约0.630 | 5段粒度使实际文本缺失约34.9%，**不能称作真实10%文本缺失实验** |
| TAV请求缺60%，中段双块 | 0.525 | 0.652 | 明显退化；实际文本约58.8%、音频约60.1%、视觉约60.0% |

文本请求10%与20%在许多样本上都被四舍五入为缺1段，因此两组数值可能相同。要严谨研究逐词10%缺失，需要保留词元级隐藏表示并重新训练，而不是把本轮5段结果改名。音视频缺失下指标波动小也不能证明充分融合；视觉遮蔽有时反而略改善结果，提示该支路存在噪声或主体问题。

## 4. 附件3与交付范围

新候选对附件3的30/30个对齐版唯一 ID 输出极性、[-3,3]强度和三类概率，类别数为负7、中性7、正16；概率和为1、均为有限值，无极性与强度符号冲突。逐样本结果在本地 `outputs/q2_transformer_A3/A3_predictions_transformer_candidate.csv`，质量标志另存本地。**附件3无标签，不能报告Accuracy、F1、AUC、MAE或Pearson。**类别和强度的最终CSV列名仍需按题面提交模板核对。

公开仓库只同步代码、聚合结论与环境说明；原始附件、逐样本预测和模型权重保存在本地。新候选若最终采用，问题三必须用同一预测主干重做解释，不能直接沿用当前基于旧线性模型的附件4解释。

## 5. 新旧候选的配对不确定性

同一728条 valid 样本上以固定种子进行2,000次配对bootstrap：新减旧 Macro-F1 为 +0.022，95%百分位区间约[-0.013, +0.057]；MAE 为 -0.045，区间约[-0.069, -0.019]。因此回归误差下降在这套重采样下较稳定，分类F1提升区间跨零，**不能断言分类改进已得到稳健证明**。该区间描述参与选模的验证集抽样波动，并非独立测试结论。复现脚本为 `q2_compare_candidates.py`。
