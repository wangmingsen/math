# 模型适配档案 · 2026 E 复杂场景下多模态情感预测的数学建模与算法设计

> 日期：2026-09-24。依据正式题面、`q1_validation_v3_summary.json`、`q2_transformer_aggregate.json`、`q3_transformer_summary.json`。本文评估“是否适合本题用途”，并非声称模型普遍优越；数值只作为现有证据。

## 审查结论

固定时间窗的三模态提取适合问1的100条全覆盖，但逐词秒数只对可靠音轨提供估计。轻量Transformer在附件2的3395条train上可以训练，并在728条valid上达到完整输入 Macro-F1 0.599、MAE 0.599；它适合作为目前的问2候选，分类优于线性基线的区间尚跨零。问3的遮蔽法能给可复算敏感性，不能单独证明情感原因，附件4人工回看已完成20条定性记录，其中1条矛盾。

## 模型档案一：固定视频时间窗三模态提取

| 项 | 本题判断 |
|---|---|
| 用途 | 问1从100段原视频生成可追溯的文本、声学、视觉序列与时间映射 |
| 类别 | 特征提取/时序对齐 |
| 数据要求 | 原视频、题给转写、媒体时长；允许局部无声/无脸 |
| 最低数据满足情况 | 100段且100个唯一ID与标签匹配；100个特征文件和时间映射均存在，满足覆盖性 |
| 核心假设 | 原视频时长可读；窗内特征可聚合；题给转写能提供文本语义但不必逐词吻合 |
| 假设成立情况 | 100条结构验证通过；仅79条ASR锚点接受，21条拒绝，不能给全量精确词级对齐 |
| 优点 | 全覆盖、原素材秒数可回看，异常不删样本 |
| 局限 | 音视频原生频率差异被窗口平均；分窗不等于真实语词边界 |
| 失效条件 | 音轨全零仍强制计算语音语义或以低匹配ASR产生词时戳时，局部证据为伪证据 |
| 验证方式 | 100条文件/主键/维度审计，典型样本原视频回看，21条异常人工记录 |
| 实现成本 | 已运行，后续需典型对齐图和论文100条总表 |
| 适配结论 | 推荐作为问1主体；词驱动对齐只能条件使用 |
| 替代方案 | 纯词驱动对齐更细，但静音和转写冲突需人工逐条纠正，工作量高；只用附件2特征不满足问1“自行生成” |

## 模型档案二：掩码统计线性基线

| 项 | 本题判断 |
|---|---|
| 用途 | 问2/3的低容量预测参照与诊断 |
| 类别 | 三分类逻辑回归 + 连续强度岭回归 |
| 数据要求 | 固定的文本嵌入、声画汇总统计、分类/回归标签 |
| 最低数据满足情况 | train3395、valid728，足以训练正则化低维头；具体有效参数数目由PCA与汇总维度决定 |
| 核心假设 | 全局汇总保留足够信号，局部顺序的损失可容忍 |
| 假设成立情况 | valid Macro-F1 0.577、MAE 0.644，证明可用作基线；不能证明其捕捉局部缺失规律 |
| 优点 | 小模型、误差和训练流程易复算 |
| 局限 | 位置和连续零块被聚合淡化 |
| 失效条件 | 同样总均值却缺失位置不同的样本会得到近似输入，无法区分前/后段缺失 |
| 验证方式 | 与同一valid上的时序候选及固定遮蔽场景配对比较 |
| 实现成本 | 已实现 |
| 适配结论 | 推荐为基线，不作为当前主模型 |
| 替代方案 | 轻量时序模型保留位置信息，但增加过拟合和解释复杂度 |

## 模型档案三：轻量共享Transformer + 教师/学生

| 项 | 本题判断 |
|---|---|
| 用途 | 问2极性/强度联合预测；冻结后作为问3预测主干 |
| 类别 | 15段token的多模态时序分类/回归 |
| 数据要求 | 附件2 aligned_50；题给标签；BERT三路输入协议、固定PCA和掩码；无需外部情感数据 |
| 最低数据满足情况 | train3395、valid728，满足轻量模型试验；2层、宽64、4头，不支持无节制加深 |
| 核心假设 | 5段×3模态仍保留足够时序结构；数值零可作弱可用性代理；训练与专项特征分布足够接近 |
| 假设成立情况 | 4850条token合同校验通过；但原始零行成因未知，不能把它当真实缺失标签 |
| 优点 | 同一模型联合输出两任务，可做位置/模态遮蔽；6个检查点整体体积小 |
| 局限 | 文本仅5段，细粒度缺失不能表达；蒸馏学生没有稳定超越教师；无单独校准可靠性门控 |
| 失效条件 | 文本主导且关键信号被截于50词元之后；或前端零值代表抽取错误时，模型将其误作低活动/不可用；两种情况都可能错误归因 |
| 验证方式 | A2 valid四指标、每类F1、169场景、三种子、同样本线性基线配对bootstrap；A3仅输出30条无标签预测 |
| 实现成本 | 已完成训练和验证；最终论文图表、可复现包尚待完成 |
| 适配结论 | 有条件推荐。分类提升尚不能称稳健显著；回归差值证据较强但仍受同valid选模影响 |
| 替代方案 | 退回线性基线可降低复杂度与选择偏差，但牺牲局部顺序；更细文本token模型能测10%缺失，却须从编码到问3解释整链重训 |

## 模型档案四：冻结模型的逐模态/局部遮蔽

| 项 | 本题判断 |
|---|---|
| 用途 | 问3对20条附件4样本输出主要参考模态、各模态作用和关键片段 |
| 类别 | 输入扰动敏感性分析 |
| 数据要求 | 问2冻结模型、A4 aligned特征与原视频、映射质量记录 |
| 最低数据满足情况 | 20/20条预测，60条模态扰动与300条局部扰动已生成；人审记录19条相符、1条矛盾，均无备注 |
| 核心假设 | 零输入扰动有可解释的方向；选择的5段足够定位；ASR估计能作为回看起点 |
| 假设成立情况 | 结果可复算，13号视觉全零造成视觉扰动为零；但零替换可能离开训练分布，ASR时间不是真值 |
| 优点 | 全量数值表和原视频审查页一一对应，允许保存反例 |
| 局限 | “主要模态”是本次遮蔽下的最大正向概率下降，不是稳定因果贡献；音视50位并非等时秒数 |
| 失效条件 | 多模态强交互时单独遮蔽可能给出零或反向差值；此时主模态排名不代表真实依赖 |
| 验证方式 | 结构核查+原视频人工审查CSV；在valid对有标签样本做错误归因分析；与不同扰动基线比较稳定性 |
| 实现成本 | 自动部分已完成，人工20段已完成；论文案例卡和图表待排版 |
| 适配结论 | 有条件推荐为“可复核敏感性解释”；未达到已验证的证据可信度结论 |
| 替代方案 | 注意力图计算更便宜却不能独立提供作用证据；音视频人工逐帧标注更直观但20条全量成本较高 |

## 逐项核对

| 维度 | 判定与证据 |
|---|---|
| 任务匹配 | 问1有自生成特征；问2有分类+回归；问3有逐条预测+模态/局部表。论文正文和终包仍未完成 |
| 数据充分性 | 问2训练3395例适合轻量网络；问3仅20无标签，不允许训练解释模型 |
| 核心假设 | aligned版本和token合同已核；原始零值成因、ASR秒数真值仍未知 |
| 参数可辨识 | 预测器参数能由train监督拟合；“真实模态因果贡献”无法由题给数据唯一识别 |
| 独立验证 | valid可评估预测，A4无标签只能人审证据；旧候选已查看test，新候选不得声称独立外测 |
| 四天成本 | 现有计算可运行；主要剩余是人审、图表、论文与提交包 |
| 匿名/模板/篇幅 | 尚无正式终稿和当届模板，不能判定通过；提交前必须单独核验 |

## 修改优先级

1. 将已收到的20条A4人工审查写入论文；重点呈现09号相符案例和15号高置信反例。
2. 在valid形成问3解释与预测错误的图和分析，不能只给A4无标签结果。
3. 完成问1的100条正文总表和对齐图；全量特征入≤50MB提交包。
4. 以当届正式模板完成匿名、摘要页、附件和MD5检查。
